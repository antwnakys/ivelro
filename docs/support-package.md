# Monthly support package (proposal)

A fixed monthly fee for keeping a client's automations, integrations, local AI system and AI search presence working and up to date. Steady income for IVELRO, peace of mind for the client.
Prices are a suggestion for the team to agree; the official prices live in the pricing sheet on the Drive.

| | Basic | Plus |
|---|---|---|
| Suggested price | 15–20 € / month | 35–45 € / month |
| Monitoring that automations and AI systems are running | ✓ | ✓ |
| Monthly check of automations, integrations and local AI systems | ✓ | ✓ |
| Small changes (message templates, rules, texts, company documents) | up to 30 min / month | up to 2 hours / month |
| Response time | 2 working days | 1 working day |
| Monthly check of how AI search tools describe the business, with corrections | | ✓ |
| Short monthly report (what ran, what changed, what we fixed) | | ✓ |

- First month free after delivery, then the client chooses whether to continue.
- Bigger changes (new automations, new integrations, new AI features, extending a local AI system) are quoted separately.
- Hardware for local AI belongs to the client; hardware faults are not covered unless agreed.
- How requests are handled is described in the "Διαδικασία Υποστήριξης Πελατών" document and in the Support and Maintenance Policy (ivelro.com/legal/support-and-maintenance/).
