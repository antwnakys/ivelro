# Monthly support package (proposal)

A fixed monthly fee for keeping a client's site safe and up to date. Steady income for IVELRO, peace of mind for the client.
Prices are a suggestion for the team to agree; the official prices live in the pricing sheet on the Drive.

| | Basic | Plus |
|---|---|---|
| Suggested price | 15–20 € / month | 35–45 € / month |
| Hosting, HTTPS and domain monitoring | ✓ | ✓ |
| Monthly check: site, form and automations work | ✓ | ✓ |
| Small changes (texts, photos, prices, hours) | up to 30 min / month | up to 2 hours / month |
| Response time | 2 working days | 1 working day |
| Google Business Profile updates | | ✓ |
| Short monthly report (visits, messages received) | | ✓ |

- First month free after delivery, then the client chooses whether to continue.
- Bigger changes (new pages, new automations) are quoted separately.
- How requests are handled is described in the "Διαδικασία Υποστήριξης Πελατών" document.
