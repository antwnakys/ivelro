# Website launch checklist

Go through this before telling the client the site is live.

## Content
- [ ] All placeholders replaced (search the files for `{{`)
- [ ] Texts checked by the client, no spelling mistakes
- [ ] Real photos, compressed (under 250 KB each), with descriptive alt text
- [ ] Phone, email, address and opening hours are correct everywhere (page, footer, Google data)

## Works everywhere
- [ ] Tested on a phone (iPhone and Android if possible), a tablet and a laptop
- [ ] No sideways scrolling on a phone
- [ ] Menu opens and closes on a phone
- [ ] Every link and button works, phone number calls, email opens the mail app
- [ ] Form: a test message arrives in the client's inbox, errors show when fields are empty

## Google and sharing
- [ ] Title and description set for every page
- [ ] Share image (og-image.jpg) looks right when the link is sent on Viber, WhatsApp or Facebook
- [ ] sitemap.xml and robots.txt have the real domain
- [ ] Site added to Google Search Console, sitemap submitted
- [ ] Google Business Profile links to the website

## Domain and security
- [ ] Domain connected, HTTPS works (padlock), `www.` redirects to the main address
- [ ] 404 page works (try a wrong address)
- [ ] Privacy policy page present and linked from the form

## Handover
- [ ] Client has the logins they need (domain, Web3Forms)
- [ ] Domain renewal date written in the client's folder
- [ ] Ask the client for a review or testimonial (Marketing & Content)
